# 岗位精选

一个无依赖、只读的中文岗位快照网站。展示已整理的岗位摘要、初筛参考分、待确认事项，以及 BOSS直聘原始岗位链接。

## 使用

- 按关键词、岗位类别、了解优先级、本次新增标记及月薪区间筛选；支持按初筛参考分或首次收录时间排序。
- 月薪区间按交集筛选，单位为 K（千元/月）。默认保留无法获取月薪区间的岗位，也可只看已知区间或只看待确认岗位。薪资保留“招聘页标注”，可能含提成、奖金等浮动部分；不猜测未知薪资，不根据标注薪数推算保底年薪。
- 展开“任职要求与记录”可阅读要求、工作语言说明、详情阅读状态和时间记录。
- 原始岗位在新窗口打开，可能需要登录源站。本站不提供账号、投递、状态标记或数据上传，不保存筛选条件。

这是单次采集快照，未设置每日采集或定时更新。首次收录时间不代表源站发布时间；时间统一以 `Asia/Shanghai` 展示。初筛参考分来自本次人工辅助的启发式判断，仅用于清单排序，不是自动评分引擎的结果，不代表已满足全部任职要求，也不是录用概率。所列岗位都是待进一步了解的线索，岗位有效性、薪资与具体条件请以源站或招聘方确认为准。

## 本地浏览

使用任意静态 HTTP 服务打开 `docs/`，例如：

```sh
python3 -m http.server 8000 --directory docs
```

访问 `http://localhost:8000`。请勿直接双击 HTML 文件：浏览器通常不允许以 `file://` 方式读取模块和 JSON。

## 文件

| 路径 | 用途 |
| --- | --- |
| `docs/index.html` | 页面结构与岗位卡片模板 |
| `docs/styles.css` | 自适应深灰与金色主题 |
| `docs/app.mjs` | 安全渲染、交互和数据读取状态 |
| `docs/model.mjs` | 数据契约、筛选、排序和时间格式化 |
| `docs/data/jobs.json` | 版本 1 的公开岗位快照 |
| `tests/` | Node 内置测试 |

快照中的 `run` 提供实际查看卡片数、详情阅读数、收录数与新增数；`jobs` 中的 `isNew` 明确标识本次新增，不根据日期猜测。未知标量字段使用 `null`，未知列表使用空数组。原始链接必须为 HTTPS 的 `zhipin.com` 域名及其子域下的 `/job_detail/<id>.html`，不得带查询参数、片段、凭据或非默认端口。每条记录的 ID 为 `boss-<id>`。

## 检查

无需安装包，使用支持内置测试运行器的 Node.js：

```sh
node --test
```

GitHub Pages 使用 `main` 分支的 `/docs` 目录。所有资产和数据使用相对路径，兼容仓库子路径部署；无需构建服务、第三方字体或追踪脚本。
